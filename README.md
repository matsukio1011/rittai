# 立体のかぞえ方研究室

立体を回転させながら、面・辺・頂点の数え方を学ぶ日本語の学習アプリです。

## 使い方

このリポジトリをダウンロードし、`index.html` をブラウザで開いてください。`app.js` は同じフォルダーに置きます。インストール・ビルド・APIキーは不要で、オフラインでも使えます。

## 機能

- 5種類の正多面体、正三角形の十六面体、画像の展開図から作る三角すいを表示
- ドラッグ・矢印キーで回転、面・辺・頂点の数と説明を表示
- 面を切り離し、形ごとに並べて数える
- 正多面体の展開図と組み立て、固定する底面の切り替え
- 正多面体の頂点を切り取り、切り口が辺の真ん中で接する深さまで調整
- PC向けの大きな図、全画面表示、ダークモード

画像の三角すいは、外枠ABCDを正方形、E・Fを辺の中点として再現しています。正六面体の切断例は辺の中点で接する形を基準とし、それ以外の切断例は辺の長さがそろう位置を基準としています。

## ファイル

- `index.html`：画面とスタイル
- `app.js`：立体の形状、描画、操作、説明

## 更新時の確認

JavaScriptの構文は `node --check app.js` で確認できます。ブラウザでは立体の選択、回転、面の分離、展開図、切断の深さ、全画面と配色の切り替えを確認してください。

切断の途中と基準位置では面の形や頂点の数が変わるため、表示中の形に対応する数を確認してください。
