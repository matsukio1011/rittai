# 立体学習ポータル (Geometry Learning Portal)

3D幾何学や立体図形の規則性を学ぶ4つのWebアプリケーションを選んで利用できるポータルサイトです。

## 収録アプリ

1. **立体のかぞえ方研究室 (`apps/kazoe/`)**
   - 5種類の正多面体（正四面体・正六面体・正八面体・正十二面体・正二十面体）や十六面体、画像の展開図から作る三角すいを観察
   - ドラッグ操作による360度自由回転、面・辺・頂点の数え方ガイド
   - 面を切り離して形ごとに並べて数える面の分解機能
   - 展開図と組み立てのアニメーションシミュレーション
   - 頂点の切断深さ調整とオイラーの多面体定理（$V - E + F = 2$）の検証

2. **立方体の切断シミュレーター (`apps/kirikuchi/`)**
   - 立方体の辺上に任意の3点（P・Q・R）を直感的に配置し、できる切り口多角形（三角形〜正六角形）をリアルタイム計算・可視化
   - 3D表示と算数・数学教材に準拠した「見取り図表示（斜投影）」の切り替え
   - 見取り図における正確な実線・点線（隠れ線）の描画
   - 辺をクリックして補助線（延長線）や切断面との交点を表示する作図支援機能
   - 切り口の2D実形プレビュー（正面図）、断面積・周長計算、代表的な切り口プリセット

3. **立体ラボ (apps/solid-lab/)**
   - 画像に合わせた頂点名で6種類の角柱を回転し、平行・垂直・ねじれの位置を練習
   - 辺と辺・辺と面・面と面の出題、採点、解説
   - 正解音・不正解音（オン・オフ可能）、正解後は約1秒で次の問題へ
   - 最新500問の履歴、不正解のみの表示、履歴から同じ立体・問題へ再挑戦
   - 連続正解数と最高記録を保存。問題文が多いときは問題欄内をスクロール

4. **なる？ならない？ 空間の直線と平面 (apps/position-lab/)**
   - 問5・問7の全8問、24通りの条件を満たす図をボタンで切り替え
   - 結論が成り立つ例と成り立たない反例を比較
   - ドラッグで回転、拡大・縮小、立体・正面・真上の視点切り替え
   - 問題全体の答えと、今の図における○・×を分けて表示。答えの表示切り替えに対応

## 使い方

ブラウザで `index.html` を開いてください。
インストーラーやサーバー構築・APIキー等は不要で、オフラインでも動作します。

- 画面上部のタブまたはホーム画面のカードから、利用したいアプリを選択して切り替えられます。
- ダークモード切り替えや全画面表示にも対応しています。

追加したアプリは、それぞれのフォルダの index.html を直接開いても使用できます。外部ライブラリやビルドは不要です。

立体ラボの履歴・連続正解・音の設定は、使用するブラウザ内に保存します。別のURLや別のブラウザの版とは共有されません。

## 追加アプリの検証

Node.js がある環境で、各フォルダから実行します。

- apps/solid-lab/: node verify.cjs、node verify-progress.cjs
- apps/position-lab/: node verify.cjs

数学的な関係、採点、履歴保存・再挑戦、自動送り、図の条件と○・×の判定を検証します。
