# 立体学習ポータル (Geometry Learning Portal)

3D幾何学や立体図形の規則性を学ぶ2つのWebアプリケーションを選んで利用できるポータルサイトです。

## 収録アプリ

1. **立体のかぞえ方研究室 (`apps/kazoe/`)**
   - 5種類の正多面体（正四面体・正六面体・正八面体・正十二面体・正二十面体）や十六面体、画像の展開図から作る三角すいを観察
   - ドラッグ操作による360度自由回転、面・辺・頂点の数え方ガイド
   - 面を切り離して形ごとに並べて数える面の分解機能
   - 展開図と組み立てのアニメーションシミュレーション
   - 頂点の切断深さ調整とオイラーの多面体定理（$V - E + F = 2$）の検証

2. **立方体の切断シミュレーター (`apps/kirikuchi/`)**
   - 立方体の辺上に任意の3点（P・Q・R）を直感的に配置し、できる切り口多角形（三角形〜正六角形）をリアルタイム計算・可視化
   - 3D表示と算数・数学教材に準拠した「見取り図表示（斜投影）」の切り替え
   - 見取り図における正確な実線・点線（隠れ線）の描画
   - 辺をクリックして補助線（延長線）や切断面との交点を表示する作図支援機能
   - 切り口の2D実形プレビュー（正面図）、断面積・周長計算、代表的な切り口プリセット

## 使い方

ブラウザで `index.html` を開いてください。
インストーラーやサーバー構築・APIキー等は不要で、オフラインでも動作します。

- 画面上部のタブまたはホーム画面のカードから、利用したいアプリを選択して切り替えられます。
- ダークモード切り替えや全画面表示にも対応しています。
